# Пособия

Android-приложение: справочник мер социальной поддержки (Россия, Приморский край, Владивосток) с ИИ-чатом.

- Встроенная база (`app/src/main/assets/measures.json`, генерируется `tools/make_db.py`): размер, кому положено, как оформить, закон со ссылкой, сроки, источник, дата проверки, признак «не проверено».
- Раздел «Заканчивается» и уведомления за 90/30/7/1 дней до окончания меры.
- «Законы»: новые акты о соцподдержке с publication.pravo.gov.ru (федеральные и Приморского края), фоновая проверка WorkManager.
- ИИ-чат: веб-режим (chat.qwen.ai и др.) и API-режим (DashScope, OpenAI-совместимый). По умолчанию `qwen3.8-omni-flash`, размышление и веб-поиск включены. Ключ хранится только в настройках на устройстве.

Информация справочная, суммы уточняйте в СФР / КГКУ «ЦСПН ПК» / МФЦ.
